## Plugin-Übertragung

Unabhängig vom Grund kann es vorkommen, dass jemand die Weiterentwicklung eines Plugins einstellen muss. Damit dies nicht zu Lasten der Nutzer geht, empfiehlt es sich, einen Beitrag im Forum zu erstellen, um herauszufinden, ob ein anderer Entwickler die Pflege des Plugins übernehmen möchte.

Sobald ein Käufer gefunden ist, müssen Sie sich nur noch an das Jeedom-Team wenden, um die Übertragung zu beantragen. Es gibt zwei Möglichkeiten:
- Eröffnen Sie eine Supportanfrage über das Market-Konto des ursprünglichen Entwicklers, indem Sie den Bereich **Technischer Support -> Entwickler** auswählen. Diese Anfrage erfolgt über die Seite **Profil** im Market, indem Sie auf die Schaltfläche **Supportanfrage eröffnen** (Schaltfläche ganz rechts) klicken,
- oder senden Sie eine E-Mail an die für Entwickler vorgesehene Adresse oder an *support[a].jeedom.com* unter Verwendung der E-Mail-Adresse, die im Market-Konto des ursprünglichen Entwicklers hinterlegt ist.
