**Plugin Icon Documentation**

In order to be published on the Jeedom Market, every plugin must have an icon.

This icon will be the one displayed to users, on the app store, and in the Jeedom interface.

You must create a file in PNG format, measuring 309 x 348 pixels.

The file name is structured as follows: `<plugin-id>_icon.png`

It must be saved in the folder `/plugin-info/`

This file is required.

We thank you in advance for not using the same color scheme as the icons for the official Jeedom plugins.

Since 2020, it is recommended that you no longer place the name under the image (be sure to keep the same dimensions as the template, though!)

Please use this template (rounded corners, size, colored background, transparency around the edges, etc.):
