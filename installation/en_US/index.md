# Installation

**Jeedom is software that is, and will remain, open source**. It is completely free to use and requires no cloud service or subscription to run.
However, some plugins may require a fee and/or an internet connection, [**The complete list of available plugins can be found on the Jeedom Market**](http://market.jeedom.fr/index.php?v=d&p=market&type=plugin){:target="_blank"}.

## Compatibility

[**Official Jeedom boxes**](/compatibility/#Boxes%20officielles) ensure full compatibility regardless of future software updates.

Jeedom can also be installed on [all supported hardware](/compatibility/#Matériels%20supportés) that supports the system [**Currently Recommended Version of Debian Linux**](/compatibility/#Debian).

## Jeedom Backup

If you need to reinstall the system, **it is essential to download a recent backup of Jeedom** that can be restored once the process is complete:

1. From the Jeedom interface, click on the **Settings > System > Backups** menu.

2. Click the **Start Backup** button.

3. When the operation is complete, click **Download Backup**.
