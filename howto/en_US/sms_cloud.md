# SMS/Cloud Calls

## Description

This is a paid service from Jeedom SAS that allows you to send text messages and make calls (with a message read by a robot) from your Jeedom.

A simple example is: if the alarm goes off, I receive a call with a voice message that tells me, for example, which zone triggered the alarm. The same can be done with a text message.

> **IMPORTANT**
>
> This service relies on the internet; if you lose your internet connection, it will no longer work

## How to Use It

It's very simple—all you need to do is:

- SMS credits: SMS = 1 credit (limited to 140 characters), call = 2 credits (limited to 450 characters)
- Get the Phonemarket plugin, install and configure it, documentation [here](/plugins/communication/phonemarket)
